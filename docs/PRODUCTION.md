19 November 2026. Domain resmi yang dipilih pemilik adalah routina.web.id dan hosting Vercel. Situs memakai Astro statis dengan build npm run build dan output dist. Halaman /en/ dan /id/ memakai canonical, hreflang, Open Graph dan sitemap pada domain resmi. Root mengikuti desain yang ada ke /en/.

Pemilik melaporkan pengujian pada Oppo A95 dengan semua alur berhasil. Versi Android dan rincian langkah belum disebutkan. Laporan ini melengkapi hasil emulator di repositori aplikasi.

APK lokal 1.0.0 build 1 memiliki 64.321.176 byte dan SHA-256 c625d6afc34034258aa00fae7b241f8f2f7f5df234af18f7c335a1d90dcb5e1e. Pemeriksaan ulang checksum dan apksigner berhasil, dengan fingerprint sertifikat c52104a534d73f1da34b5045ce32678b01023fc11eb799c9ae471d03ed2b08fc.

Manifest kandidat masih mencatat PENDING_RELEASE_CHECKLIST. Uji upgrade signed, runtime 16 KiB dan overflow onboarding 320 dp dengan teks 200% masih tercatat terbuka dalam audit aplikasi. Kontak telah tersedia. Kebijakan privasi dan catatan rilis perlu diselesaikan sebelum aktivasi unduhan publik.

Konfigurasi DNS harus mengikuti nilai yang diberikan untuk proyek ini di Vercel. Pemeriksaan awal domain menghasilkan DNS server failure dan HTTPS belum dapat diakses.
